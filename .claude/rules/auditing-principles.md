# 审计原则

本规则只管证据质量与问题分级；类型专属审计流程留在相应 skill 与 references。

- 信工具前先校准：读真实代码路径，确认静态分析盲区与运行时构造。
- 优先执行证据。作品基础链是 `graph-audit.mjs`、`assembly-probe.mjs` 与默认 build；jsdom smoke 仅在已安装时可选，浏览器结论只在真实执行后成立。
- 区分已确认问题与仍需运行/人工验证的候选；每个确认项给复现、路径和观察输出。
- 确定性闸非零就是待修失败，不能用意见覆盖；反之也不能把启发式怀疑冒充已确认缺陷。
- 发现误报要明确撤回，并记录原方法为什么不可靠。
