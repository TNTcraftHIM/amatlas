# DEBUG 管线日志

仅当项目根存在 `DEBUG` 文件时生效；没有 `DEBUG` 就不做任何事。

每完成一个有意义步骤，向 `PIPELINE-LOG.md` 追加短记录：

- 这一步及读取的文件/reference；
- 决策、放弃的备选与原因；
- 遇到的不确定或阻塞；
- 用来检查结果的命令或观察。

日志是诊断记录，不是完成证明。只记录真实的 `graph-audit.mjs`、`assembly-probe.mjs` 与 build 结果；jsdom smoke 仅在已安装时可选。自动、可选、人工检查要分清；未实际执行就不得声称浏览器验证、交互覆盖或测试通过。仍待验证的步骤不能因写入日志就标为完成。
