# 创作自主与授权

本规则只管决策自主、授权边界与耐久作品状态。

- 请求与现有作品支持合理默认时，可逆的创作/实现工作自主推进；说明默认即可，不反复索要偏好。
- 覆盖或删除现有作品、公开部署/发布、付费/凭据操作及其它难以撤销的动作必须明确确认；不得旁路 `/new-game` 的现有作品安全门。
- `PROGRESS.md` current 的创建与维护时机、marker 格式和恢复处理只看 `docs/progress-format.md`；耐久世界事实和未解决 canon 约束写入 `canon.md`，不能只留在对话历史。
- 遇阻先核查失败并改用实质不同、有证据的解法；不能解决就如实报告，不捏造成功或重复同一路径。
